# Kurdistan Autonomous AI Business Engine (AI Garm / AI گرم)

An elite, localized business automation and execution agent engineered for commercial ecosystems in Iraq and the Kurdistan Region (Erbil, Duhok). AI Garm optimizes regional operations across car dealerships, pharmacies, and wholesale distribution, offering multi-lingual commercial support (Badini Kurdish, Sorani Kurdish, and Iraqi Arabic), live web searches, web scraping, and automated business workflows.

---

## Features

- **Regional Localization:** Instant generation of high-conversion sales pitches and client acquisition templates in Badini Kurdish, Sorani Kurdish, and Arabic.
- **Autonomous Web Scraping & Search:** Real-time data collection and web search integration via Python and DuckDuckGo/BeautifulSoup.
- **Flask REST API:** Lightweight, high-performance web endpoints designed to plug directly into low-code automation tools like n8n, Make, or custom front-ends.
- **Zero-Cost Architecture:** Built entirely on open-source libraries and free-tier hosting pipelines.
